# AI Fellow

- **Organization:** Break Through Tech AI Program, Cornell Tech
- **Role:** AI Fellow
- **Cohort:** April 2026 – 2027
- **Status:** Current

Free, one-year virtual extracurricular program preparing undergraduates for careers in data science, machine learning, and AI.

## Program

- Begins with a rigorous 9-week Machine Learning Foundations course (curriculum by Cornell Tech) over the summer. Completing it earns a machine learning certificate from Cornell University.
- ML Foundations covers analyzing real-world datasets, building data analysis pipelines, and using common ML/AI libraries to build, train, and validate models in a business context.
- Fall/Spring AI Studio: matched with a team of fellows to solve a real-world ML challenge proposed by an industry host company, with an industry Challenge Advisor and academic guidance. The work is meant to produce a portfolio-quality project.
- Ongoing small-group industry mentorship: case studies, skill-building simulations, and personalized feedback.
- Career support: resume, LinkedIn, and GitHub portfolio development, interview prep, and internship placement support.

## What I learned / built

- Completed an intensive machine learning curriculum covering the full ML lifecycle, from data preprocessing and feature engineering to model deployment and evaluation.
- Built, trained, tuned, and evaluated supervised learning models including Logistic Regression, K-Nearest Neighbors, Decision Trees, and Neural Networks using Python and real-world datasets.
- Completed an end-to-end deep learning pipeline by designing, training, optimizing, and evaluating neural network models with TensorFlow and Keras.
- Designed and developed an LLM-powered chatbot, applying prompt engineering and conversational AI principles.
- Built a complete Retrieval-Augmented Generation (RAG) chatbot using LangChain, implementing document ingestion, semantic chunking, embeddings, vector database retrieval, and LLM-powered response generation.
- Performed exploratory data analysis (EDA), feature engineering, hyperparameter tuning, model validation, and technical reporting through data visualizations and documentation.
- Working with a team of 3 other fellows on an ML model that predicts an auto insurance claim estimate for Allstate. The team owns both development and project management: breaking the goal into sprints, assigning roles, staying aligned through communication, and producing project deliverables.
