# Job finder

Job finder keeps internship searches for Nevaeh Dickerson in one place. It records which internships to look for, how an agent should search, and the listings that matched.

| File | What it is |
| --- | --- |
| [internship-preferences.md](internship-preferences.md) | Roles, timeline, locations, skills, sources, and search days |
| [jobs.md](jobs.md) | Clear matches, then close matches to review. Each section is earliest date posted first |
| [application-tracker.csv](application-tracker.csv) | Spreadsheet of the same listings, with application status. Opens in Excel or Google Sheets |
| [../.cursor/rules/job-finder-internships.mdc](../.cursor/rules/job-finder-internships.mdc) | Agent guideline: search only from the preferences file |

The preferences were drafted from [my-experiences](../my-experiences/). Edit that preferences file when a target role, term, or location changes. New searches should follow the edited file.
